Patch Notes

System Update History

v0.6 - Alerts, Auido, & Stability
DEC 31, 2025

GherkinBot just got a major upgrade. This patch focuses on stability, audio compatibility, and a complete visual overhaul for stream alerts.

  • UI Armored Carbon Skin: Complete redesign of the Sound Alert card with high-def carbon mesh, heavy 3D metal bevels, and holographic neon-green sheen.
  • AUDIO Audio Engine 2.0: Added full support for .WAV and .OGG files. Rewrote the asset server to handle filenames with spaces.
  • FIX Alert System: Resolved critical issue where overlay alerts would trigger but fail to display images or play sounds in production builds.
  • FIX Stream Manager: Updated Twitch API permissions to reliably update Stream Title, Game, and Tags without silent failures.
  • FIX Auto-Updater: Patched repository connection logic. GherkinBot can now self-update reliably when new features drop.
  • SYSTEM Startup Stability: Fixed "White Screen" launch issue by re-routing the resource path loader.
  • SYSTEM Optimization: Removed legacy debug console and cleanup code for a faster, silent background startup.
v0.4 - WIDGETS & POLISH
DEC 18, 2025

This update introduces the first Premium Widget, major stability fixes for the CRM, and a UI overhaul preparing for the tier system.

  • WIDGET Death Counter: Added fully interactive counter with custom backgrounds, fonts, and hotkey support.
  • UI Tier System: Added visual "Plus" and "Premium" tags to prepare for upcoming tier restrictions.
  • AUDIO Soundboard: Added "Reset Slot" functionality and fixed channel point header glitches.
  • BOT User Profiles: Fixed chat history tracking and follow date calculation.
  • SYSTEM Overlay: Separated widgets into dedicated files (death.html) for better OBS layout control.
v0.1 - ALPHA LAUNCH
DEC 16, 2025

The initial public release of GherkinBot. This build focuses on core stream management and chat interaction.

  • CORE Dashboard: Added View Counter, Chat Activity, and Latest Activity feed.
  • CORE Quick Actions: Added Poll Create, Raid, Clip, and Stream Marker buttons.
  • CORE Protection: Added toggles for Block Links, Caps Filter, and Emote Spam.
  • CORE Auto-Raid: Added "Auto Raid SO" to automatically shoutout incoming raiders.
  • STREAM Details Tab: Ability to update Title, Category, and Tags.
  • STREAM Live Chat: Integrated chat view within the details pane.
  • BOT Announcements: Added Timed + Activity hybrid logic.
  • BOT Chat Bot: Added Custom Commands engine.
  • BOT Alerts: Added Custom Alert System for stream events.
  • AUDIO Soundboard: Support for Hotkeys and Channel Points.
  • UI Audience: Added Subscriber List view.
  • WIDGET Omni-Bar: First widget available for browser sources.
