# GherkinBot - Official Website & Documentation Hub

![GherkinBot Mascot](app-preview.png)[cite: 3]

This repository contains the front-end web architecture for **GherkinBot**. While the core application handles the heavy API routing in Java, this lightweight web project was built to market the product, distribute releases, and host the official technical documentation.

## Project Status: Archived
Just like the core application, this website is currently archived. It was built to solve a specific business need while I was actively streaming. Since I have pivoted my focus away from content creation to pursue enterprise IT and automation, the site has served its purpose. It remains here as a demonstration of my front-end web development, UI design, and technical writing skills.

## Core Web Features

* **Technical Documentation (`docs.html`):** A comprehensive "Field Manual" providing users with structured, step-by-step instructions for software installation, Twitch API token authorization, and configuring OBS browser sources. 
* **Version Control History (`changelog.html`):** A detailed "Patch Notes" timeline documenting system update history, bug fixes, and feature rollouts (such as the Audio Engine 2.0 update and startup stability patches) to keep users informed.
* **Product Branding:** Implements a cohesive dark-mode UI with a neon green aesthetic, utilizing CSS grid layouts and custom graphics to create a professional product storefront[cite: 3, 5, 8].

## Tech Stack
* **Frontend:** HTML5, CSS3
* **Typography & Icons:** FontAwesome API[cite: 5, 8]
